# Feature 036 - MP 180 Hz tick

Raise shared **`TICK_HZ`** to **180**. Server fixed-step, client drive publish interval, and estimated-tick math all derive from `game_net::TICK_HZ`. Wire shapes from **034** / **035** stay the same. Bump **`protocol`** so mixed-rate peers cannot join.

Depends on **035**.

## Numbers

| | Was | Now |
| --- | --- | --- |
| `TICK_HZ` | 30 | **180** |
| `PROTOCOL_VERSION` | 2 | **3** |

## Acceptance criteria

- Client and server run at 180 Hz (`TICK_DURATION_SECS = 1/180`); drive samples while joined target about that rate.
- Protocol mismatch rejects join against older builds.
- Solo play unchanged.
